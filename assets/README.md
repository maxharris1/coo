# Assets

Production assets for the app. Copy this folder to `public/assets/`. Everything was generated by
the drawing code in `reference/generator/`, the same code that drew the screens, so files and
mocks match.

| Path | What |
|---|---|
| `tokens.css`, `tokens.json` | Colours, fonts, radii, outline, shadows |
| `motion.css`, `motion.json` | 38 keyframes with duration, easing and use |
| `fonts/` | Bagel Fat One 400, Nunito 600 to 900, Caveat 600 and 700 (woff2, Latin, SIL Open Font License) |
| `svg/birds/<look>/<pose>.svg` | 5 birds x 10 static frames. All face right |
| `svg/birds/breeds/` | The 6 hatchable breeds, static |
| `rig-reference/` | 111 animated birds: every look and breed in every pose, 12 dressed examples, and `takeoff.html`. Expected output for the Bird component. `index.json` maps files to props |
| `svg/gear/icons/` | Closet and store icons, 32 grid |
| `svg/gear/overlays/` | The same items in bird coordinates (viewBox -10 -22 140 132) for static compositing |
| `svg/icons/` | 49 interface icons, 24 grid, `currentColor` |
| `svg/illustrations/` | 24 props and scene pieces |
| `svg/map/` | Route pins, and the illustrated map's decorations (`svg/map/night/` for night). See `docs/09-map.md` |
| `svg/loft/` | The loft scene cut into one SVG per piece, and `loft-tokens.css` for their classes. See `docs/17-loft-scene.md` section 10 |
| `app-icon/` | SVG masters and PNG exports (16, 32, 180, 192, 512, maskable 512) |
| `map/` (repo `assets/map/` only) | `coo-night.overrides.json`, the night values `src/app/dev/map/night.ts` swaps into the day style, and `map-colours.json`, the illustrated map's regional, street and night colours. The styles the app serves are in `public/map/`. See `docs/09-map.md` |
| `data/birds.json` | Palettes for each look and breed |
| `copy/empty-states.json`, `copy/voice.md` | Empty-state lines and the voice rules |
| `preview/motion.html` | Every animation running |

Gear definitions, breeds, game numbers and the rest of the copy are in `config/`, not here.

Layer order for a dressed static bird: pose, neck item, head item, leg item.
